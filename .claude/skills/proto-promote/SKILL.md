# Перенос прототипа в основной

Правила из `CLAUDE.md` проекта вынесены сюда, потому что нужны только при переносе или отклонении прототипа. Правила `index.html`, прототипов, публикации и интерфейса — в `CLAUDE.md`.

По просьбе «перенеси из прототипа NN в основной …»:
1. Посмотри изменения: `git log -- <файл>` и `git diff <коммит-копии> HEAD -- <файл>`. Если после последней правки прототипа полной проверки не было, сначала проверь его (`CLAUDE.md`, пункт «Проверки прототипа» в разделе «Всё остальное — в прототип»).
2. Перенеси в `index.html` только то, что попросили, поверх текущего `index.html` (он мог уйти вперёд). Правила интерфейса соблюдай на перенесённых участках, остальное не трогай.
3. Проверки из `api/TESTS.md` (см. `CLAUDE.md`, раздел «index.html — только согласованное»). Коммит: `Макет: из прототипа NN — <что>`, плюс запись в `CHANGES.md`.
4. В `protos.html` поставь прототипу статус «принят» (или «частично принят»).
5. Обнови отчёт о пробелах против Axxon One (`docs/axxon-one-gaps.html`) сам, без просьбы: пункты с этим прототипом в `PROTO` переведи в `DONE` или в `partial` — `docs/axxon-one-gaps.md`, раздел «Прототипы», шаг 2. Пункт не закрыт из-за контракта — строка в `WAIT`: чего нет в контракте и какой запрос это просит (там же, раздел «Пункт ждёт контракта»). Отклонённый прототип — шаг 3 там же. Коммит: `Исследование: пробелы против Axxon One — перенос прототипа NN`.
6. Принятое удали — после переноса оно мусор: два файла с одним и тем же расходятся, и непонятно, какой смотреть.
   - Прототип принят целиком — удали файл (`git rm`), в том числе чужой: просьба перенести и есть явная просьба. Строку в `protos.html` оставь: имя файла без ссылки с пометкой «(удалён)», статус «принят: …», как у прототипа 37. Отдельный коммит: `Прототип NN: удалён — перенесён в index.html`.
   - Принят частично — файл оставь: в нём ещё есть то, что не решено. В статусе перечисли, что перенесено. Когда остальное перенесут или отклонят — удали, как выше.
   - По просьбе «отклони прототип NN» — статус «отклонён: почему», файл удали (`git rm`), коммит `Прототип NN: удалён — отклонён`. Строки прототипа в `PROTO` отчёта `docs/axxon-one-gaps.html` убери (шаг 5). Его добавления в контракт сними, как отклонённую владельцем правку (скилл `api-contract`), если на них не держится `index.html`; в уведомлении о них допиши, что добавленное снято, — закроет владелец.
   - Ссылки на удалённый файл в живых документах (`*.md`, `protos.html`, другие прототипы) замени на имя с пометкой «(удалён)»; `CHANGES.md` и всё в `api/requests/` (запросы, уведомления, ответы) — история, их не трогай. Файл остаётся в git: `git log --all -- <файл>`, затем `git show <коммит>:<файл>`.
