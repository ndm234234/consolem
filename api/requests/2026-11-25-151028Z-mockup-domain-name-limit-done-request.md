# Запрос от команды mockup: правила имени объекта в описании вида (`UnitKind.nameSchema`) внесены в контракт 0.38.0 — проверить

2026-11-25 · коммит контракта `fa0e654` · от команды mockup

Кому: владелец контракта

**Статус: новый**

## Что мы сделали

Пробел F84 отчёта против Axxon One (`docs/axxon-one-gaps.html`): у Axxon One отображаемое имя домена — не длиннее 100 знаков (веб-конфигуратор, `MAX_NAME_LENGTH = 100`). У `Unit.name` в контракте предела нет. Команда mockup сама добавила механизм — только новое, ничего не сняли.

Коммит `fa0e654` («Макет: имя домена — не длиннее 100 знаков (пробел F84) …»). Версия контракта — 0.38.0. Описание — `api/README.md`, «Что добавлено в 0.38.0»; строка 0.38.0 в `docs/contract-layers/versions-by-layer.md` (слой — механизм).

## Что проверить

1. **Поле `UnitKind.nameSchema`.** Необязательно: правила `Unit.name` у объектов вида — `minLength`, `maxLength` (в знаках Unicode, после обрезки пробелов по краям), `pattern`. Нет поля — правил нет, как раньше. Незнакомое ключевое слово клиент пропускает. Вид `domain` набора `demo` (и собранных `one-domain`, `large`, `xl`) — `nameSchema: {"maxLength": 100}`. Тест «Домен: вид называет правила имени — nameSchema.maxLength 100…» (`tests/api-domains.js`, слой механизма) проверяет только описание вида.
2. **Просьба: отказ сервера на длинное имя.** Встроенный сервер правила `nameSchema` не судит: отказ на прежнем запросе — ломающая правка, её делает только владелец. Если согласны: хук `core.domain/1` (`api/profiles.js`, рядом с `NAME_REQUIRED`) отклоняет имя длиннее `nameSchema.maxLength` — `422`, код на ваш выбор (например, `VALIDATION_FAILED` или новый `NAME_TOO_LONG`), `field: /name`. Что сломается: клиент, который сейчас сохраняет имя домена длиннее 100 знаков. `index.html` такого имени не шлёт.

## Сверх запросов

- `index.html` проверяет только `maxLength` и только у видов домена: при переименовании в дереве и в карточке. Ошибка поля карточки теперь закрывает план и «Применить» (`cardEditBlock`): у предела нет отказа сервера.
- Знаки считаем как кодовые точки Unicode (`[...name].length`). Веб-конфигуратор Axxon One считает `name.trim().length` (UTF-16): разница только у знаков вне BMP.
- Системного имени домена (DisplayId) и правил его знаков (латиница, цифры, дефис — пробел F86) в контракте нет: решение владельца макета, F86 снят.
