## Что нужно от владельца договора

1. **Поле `answer.learn` принято:** имена `learn`, `catalog`, `topic`, `chapter`, закрытая схема `AssistLearnLink`, ссылка только у `answer`, ссылка годится только для каталога той же `version`.
   - Версию контракта не повышаем, она остаётся 0.2.0. Контракт ещё в разработке, ломающие правки пока допустимы. Форма объявлять поддержку `learn` не должна.
   - `maxItems: 3` в схему не ставим. Ограничение «от одной до трёх» остаётся в описании поля.
2. **Каталог принят:** формат `consolem-learn-catalog/1`, правило отпечатка, `learn-catalog.json` в сборке и `tools/learn_catalog.mjs`. Сборке с обучением нужен Node.js, сборке `--without-learn` он не нужен. Это записано в `api/BACKEND.md`, договорённость «Ассистент: учебные ссылки».
3. **Прежние числовые адреса подтверждены:** `?tour=K&demo=N` и `#learn=K.C` больше не адрес. Консоль обрабатывает их как неизвестный ID, перехода на новые адреса нет.
4. **Тема `assistant` принята:** тексты и состав из шести глав. Тексты соответствуют `docs/TEXTS.md`.
