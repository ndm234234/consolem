## Что проверить

1. **`codec` правится.** Раньше поле было только для чтения. Тип — строка без `enum`: набор кодеков зависит от устройства, `examples` — подсказки (`H.264`, `H.265`, `MJPEG`). Поле с `x-dev`. Ваш бэкенд может записать кодек в устройство?
2. **Новые параметры устройства, все с `x-dev`:** `codecProfile` (`baseline`, `main`, `high`), `bitrateMode` (`vbr`, `cbr`), `bitrateKbps` (целое, от 64), `quality` (целое 1–6; это и «Сжатие» Axxon One), `gopFrames` (целое, от 1), `smartCodec` (флажок; поля нет — выключен). Пределы общие; части `allOf` по драйверу мы не делали. Какие поля ваш бэкенд отдаёт и пишет?
3. **Новые поля консоли, без `x-dev`:** `enabled` (поля нет — поток включён), `liveUse` (поля нет — поток можно выбрать над видео), `deviceProfile` и список `deviceProfileOptions` только для чтения (профиль устройства, например ONVIF, который отдаёт поток; поля нет — профиль выбирает драйвер). Ваш бэкенд знает список профилей потока у камеры?
4. **Имя потока** — общее поле `name`: вид `stream` уже объявляет `rename`. Новых полей нет.
