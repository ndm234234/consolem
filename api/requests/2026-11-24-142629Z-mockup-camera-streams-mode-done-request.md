## Что проверить: п. 1 ответа

1. **Флажок `streamsMode`** — свойство вида `camera` в `demo.json`: `string`, `enum: ["device", "console"]`, `default: "device"`, подписи `x-label` и `x-enum-labels` («Использовать настройки устройства», «Отправлять настройки устройству»). Профиль `vms.camera/1` 1.4 описывает поле; строка истории профиля называет ваш ответ.
2. **Части `allOf` схемы камеры.** Их три, по одной на каждую ветку драйвера, где есть поля `x-dev`: `if` — условие ветки (`driver`, у PTZ ещё `ptz`) и `streamsMode: {const: "device"}`; `then` — `readOnly: true` у полей `x-dev` этой ветки. Вложенные ветки (`micEnabled`, `digitalPtz`, `camMotion`, `defaultEnablePatrol`) повторены вложенным `allOf` с теми же условиями: их поля `x-dev` тоже только для чтения.
3. **Нет поля — `device`.** `streamsMode` нет в `required` условия: по JSON Schema `properties` без значения проходит, и камера без поля получает `readOnly`. Так умолчание `device` действует у камер, у которых поля нет.
4. **Отказ — общий `422`.** Правку поля `x-dev` в режиме `device` сервер отклоняет `422 VALIDATION_FAILED`, `params.keyword: "readOnly"`. Правка `{streamsMode: "console", <поле x-dev>: …}` одним запросом проходит: схему объекта сервер решает по слитому целому.
5. **`api/README.md`**, строка `x-dev` таблицы «Расширения описаний», называет `streamsMode`, его значения и `422`.
6. **Тест** `tests/api-units.js`: «Камера: streamsMode device — поля x-dev только для чтения, console — правятся». Он проверяет схему объекта в обоих режимах, отказ `422`, правку флажка вместе с полем, вложенные поля `x-dev` и отказ на незнакомое значение флажка. Числа тестов в `api/TESTS.md` поправлены.

## Сверх запросов

- **Части `allOf` по веткам драйвера, а не одна часть со всеми полями `x-dev`.** Одна часть добавила бы в схему объекта камеры без этих полей «пустые» свойства `{readOnly: true}` без типа и подписи (`unitSchema` сливает свойства части с остальными). Условие ветки в `if` этого не допускает.
- **`streamsMode` у вида `ipsrv`** (регистратор) — данные вида, `x-hidden: true`, без частей `allOf`: у регистратора полей `x-dev` нет. Переключатель регистратора пишет `streamsMode` регистратору и каждой его камере шагом плана карточки: «только для чтения» сервер решает по `streamsMode` самой камеры.
- **У камеры `streamsMode` без `x-hidden`**: поле профиля, его рисует переключатель окна камеры; форма «Все параметры» показывает его выбором.
- **`index.html`.** Заглушек `cvCfgOf(n).mode` и `ipsModeOf` больше нет. Шаг `streamsMode: "console"` идёт в операции первым, `"device"` — последним. Выключение снимает из черновика неприменённые правки полей `x-dev`. «Сбросить к умолчаниям» сам включает режим шагом плана; у камеры регистратора он отказывает, пока признак выключен у регистратора.
- **Отчёт о пробелах:** AX2 закрыт, строки `WAIT` и `NEED` о `streamsMode` сняты.
