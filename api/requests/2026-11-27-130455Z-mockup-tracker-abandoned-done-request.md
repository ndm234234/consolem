## Что проверить

1. **`autoSensitivity`** (boolean): трекер сам подбирает чувствительность к движению и к оставленным предметам; `sensitivity` и `abandonedSensitivity` тогда не действуют. Нет поля — `false`, как раньше.
2. **`longTimeUnattended`** (boolean): трекер ищет предметы, которые лежат без движения дольше `longTimeIdleSec`. Действует, когда поиск оставленных предметов идёт (`detectUnattendedObjects`). Нет поля — `false`, как раньше.
3. **`longTimeIdleSec`** (integer, 15–1800): сколько секунд предмет лежит без движения, чтобы трекер счёл его надолго оставленным. Нет поля — 60. Вне 15–1800 — `422 VALIDATION_FAILED` по схеме вида.
4. **Нет возможности.** У всех трёх полей `absent: unsupported`: система без такой возможности не кладёт поле в схему вида, и консоль поле не показывает. Есть ли эти поля у вашего бэкенда?
