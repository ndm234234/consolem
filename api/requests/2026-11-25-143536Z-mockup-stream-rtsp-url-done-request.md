Поле RTSP формы «По адресу» принимает до трёх адресов через «;», как в Axxon One. Первый адрес — `rtspUrl` камеры. После добавления камеры консоль правит её второй поток (`PATCH /units/{uid}`) или создаёт потоки `POST /units` с `rtspUrl`. На вкладке «Видео» у каждого потока есть поле «Адрес RTSP».

## Что проверить

1. **`rtspUrl` потока** — строка, необязательная, без `x-dev`. Это свой адрес RTSP потока. Поля нет — поток идёт по `rtspUrl` камеры. Сервер только хранит и отдаёт значение: новой проверки и нового отказа нет, потоки по адресам сервер сам не создаёт. Ваш бэкенд может брать поток камеры по своему адресу?
2. **Основной поток.** У основного потока консоль поле не показывает для правки: его адрес — `rtspUrl` камеры. Если ваш бэкенд хранит адрес и у основного потока, скажите: тогда мы опишем, какое значение главное.

## Сверх запросов

- Решение mockup: адрес лежит у потока, а не строкой «адрес; адрес» в `rtspUrl` камеры. Так `rtspUrl` камеры не меняет смысл, и правка остаётся только добавлением.
- Больше трёх адресов консоль не принимает (предел Axxon One). В профиле предела нет: число потоков задаёт камера.
