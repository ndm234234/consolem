## 1. Каталог из одного источника с турами

**Что изменено.** `Tour.catalog()` (`assets/tour.js`) строит каталог из тех же тем, что исполняет показ
(`assets/tour-demos.js`). Второй копии текстов нет. Форма:

```json
{
  "format": "consolem-learn-catalog/1",
  "version": "sha256:<64 hex>",
  "available": true,
  "topics": [
    { "id": "rules", "title": "…", "goal": "…", "lang": "ru", "fixture": "demo",
      "chapters": [ { "id": "rules.simple", "title": "…", "goal": "…", "lang": "ru", "fixture": "demo" } ] }
  ]
}
```

- `goal` — поле `why` источника. `lang` — язык показа: шаги ищут элементы по русским подписям, поэтому `ru`.
  `fixture` — учебный набор встроенного сервера (`demo`). Тема или глава может задать свои `lang` и `fixture`.
- Шагов, `before`, селекторов и команд в каталоге нет.
- `version` — SHA-256 строки `JSON.stringify({format, topics})`, ключи в этом порядке. В Python то же даёт
  `json.dumps(…, ensure_ascii=False, separators=(",", ":"))`. Отпечаток меняется при любой правке каталога: ID, порядок,
  название, цель, язык, набор. Правка текста шагов его не меняет.
- `available` — материал можно запустить в этой поставке: есть движок и сервер показа.
- Главы без устойчивого ID в каталог не входят. Так главы прототипа 33 (`tour-modes-33.js`) в основной каталог не попадают.

**Место поставки (предложение).**

- в сборке WebUI — файл `learn-catalog.json` рядом с `index.html`, в `MANIFEST.json` (`tools/build_webui.py`);
- инструмент: `node tools/learn_catalog.mjs [--out FILE]` исполняет те же `tour.js` и `tour-demos.js` и печатает тот же каталог;
- на странице — `Tour.catalog()`.

С `--without-learn` в сборке лежит тот же файл с `"available": false`, `"version": null`, пустым `topics` и `reason`.
Для этого Node.js не нужен. Сборка с обучением теперь требует Node.js: каталог пишет `tools/learn_catalog.mjs`.

**Файлы.** `assets/tour.js`, `tools/learn_catalog.mjs` (новый), `tools/build_webui.py`, `tools/check_webui.py`
(`--without-learn`), `tests/ui-learn.js`.

**Совместимость.** Сборка получила новый файл: перечень файлов и SHA-256 в `MANIFEST.json` меняются. Остальные файлы
сборки прежние, кроме изменённых этим набором коммитов.

**Как проверить.** `node tools/learn_catalog.mjs`; `python3 tools/build_webui.py` и `--without-learn` —
`learn-catalog.json` в папке сборки; `tests/ui-learn.js` сверяет файл сборки с каталогом страницы.

## 2. Устойчивые ID

**Что изменено.** У каждой главы в `assets/tour-demos.js` своё `ch.id`. ID главы — `<тема>.<глава>`, например
`tree.slices`, `rules.simple`: он однозначен в каталоге и не зависит от места. Перестановка, переименование
и новая соседняя глава ID не меняют. ID удалённой главы другой главе не дают: это правило записано в начале
`tour-demos.js`. Формат ID — `[a-z][a-z0-9-]*`, тема `home` занята первым экраном раздела.

- Адрес показа — `?tour=<тема>&ch=<глава>&demo=` (`&all` — вся тема). Номер шага в `demo` только продолжает главу
  после «Назад»: шаг вне главы адреса — начало главы.
- Адрес раздела — `#learn=<глава|тема|home>`.
- `Tour.find`, `Tour.url`, `Tour.play` работают по ID. Номер темы и главы этой же страницы (так зовут `Tour.play`
  прототипы 30 и 33) переводится в ID на месте: страница и показ — одна загрузка.

**Неизвестный ID.** Неизвестная тема или глава ближайшую главу по номеру не запускает. В показе — панель
«Глава не найдена» и «Открыть каталог», страница остаётся на учебных данных. В разделе: неизвестная глава — её тема,
неизвестная тема — первый экран, в обоих случаях тост.

**Прежние числовые адреса.** `?tour=1&demo=3` и `#learn=0.1` не считаются адресом: поведение — как у неизвестного ID.
Нужно решение владельца (ниже).

**Файлы.** `assets/tour-demos.js`, `assets/tour.js`, `index.html` (раздел «Обучение», переход из поиска), `tests/ui-learn.js`.

**Как проверить.** `tests/ui-learn.js`: ID без повторов, перестановка и удаление главы на проверочной теме,
неизвестная глава и тема, прежний номер темы, `#learn=0.1`.

## 3. Учебные ссылки в `answer`

**Что изменено.** В `api/openapi.json`:

- `AssistEvent.learn` — необязательный массив `AssistLearnLink`, `minItems: 1`, в описании — не больше трёх.
  Только у `answer`: на просьбу научить или на вопрос о системе, к которому есть подходящая глава (ответ по данным
  и ссылка, как делает служба w2c — раздел «Живая служба w2c уже отвечает ссылками»). `maxItems` не поставили: сверка схем контракта (`check_api.py`, `contract.js`) его не понимает.
- `AssistLearnLink` — закрытая схема `{catalog, topic, chapter}`: `catalog` — `version` каталога
  (`^sha256:[0-9a-f]{64}$`), `topic` — ID темы, `chapter` — ID главы `<тема>.<глава>`.
- Описание `answer` в `x-enum-descriptions` дополнено.

Версию контракта (0.2.0) мы не повышали: это решение владельца договора.

**Заглушка** (`api/server.js`, `assistLearnStub`). Просьба «как» + глагол в неопределённой форме («покажи, как создать
правило», «как настроить детекторы») — `answer` и ссылки на лучшие главы каталога по словам просьбы.
**Учебный ответ — только когда глава нашлась.** Каталога нет, материал недоступен или подходящей главы нет — заглушка
разбирает просьбу прежним порядком, как на `cb728a4`, без `learn`: выгрузка → отбор → вопрос о системе → правило →
команда → правка. Так «как выгрузить видео с камеры …» по-прежнему даёт план выгрузки, а в сборке без обучения
«как создать правило» получает тот же ответ, что раньше. «Покажи» без «как» — прежний отбор `found`.
Каталог серверу даёт страница: `ConsolemServer.create({learn})`. В `index.html` это `Tour.catalog`, у стенда
`serve_api.mjs --webui` — `learn-catalog.json` сборки, как у бэкенда консоли. `tests/harness.js` берёт каталог теста
из `window.ApiTestLearnCatalog`.

**Форма** (`index.html`). Из ссылки консоль берёт только `catalog`, `topic`, `chapter` и сверяет их со своим каталогом.
Карточка «Открыть учебный пример» показывает название главы, тему, цель, время и «на учебных данных». При английском
интерфейсе и русской главе карточка показывает «the demo runs in Russian». URL, HTML, JavaScript и селекторы из ответа
не исполняются. `answer.text` остаётся текстом. Приход события ничего не открывает: показ запускает человек кнопкой (п. 4).

**Документы.** `api/BACKEND.md` — договорённость и формат каталога; `api/README.md` — режимы `?tour`, `?demoFail`
и запрет службы в учебном режиме; `api/TESTS.md` — `api-assist`, обучение в сборке.

**Совместимость.** Ответ без `learn` — прежний `answer`. Строгий потребитель старой схемы `AssistEvent`
(`additionalProperties: false`) не примет `answer` с `learn`. Поэтому бэкенд должен слать `learn`, только когда форма
обновлена. Как это объявлять (версия контракта или возможность), решает владелец договора. `AssistTurnRequest`
не менялся.

**Как проверить.** `python3 tools/run_api_tests.py` (новый тест в `tests/api-assist.js`: с каталогом и найденной главой —
`answer` с `learn`; «как выгрузить …» с камерой — план выгрузки; без каталога, с недоступным каталогом и с каталогом без
подходящей главы — одни и те же события, без `learn`), `tests/ui-assist.js`:
карточка, неизвестная глава, чужая версия, разметка, адрес и код из ответа, старый `answer` без `learn`.

## 4. Запуск показа: та же вкладка (изменено решением владельца VMS)

Отдельную учебную вкладку и `noopener` **не делаем**: так решил владелец VMS (ADR-VMS-0004, дополнение (1)).
**w2c снимает своё прежнее условие из ответа [093202Z](2026-11-05-093202Z-mockup-learn-section-console-response.md)
об отдельной вкладке.** Учебная вкладка не нужна. Вместо неё — предупреждение, полоса и выход. Следствие принято
владельцем: **на время показа в этой вкладке рабочие тревоги не приходят**.

**Что изменено.**

- Показ запускает только человек: кнопка в разделе «Обучение» или на карточке ассистента. Событие SSE показ
  не запускает.
- Перед запуском — предупреждение: «На время показа эта вкладка не получает рабочие тревоги и события». Текст
  предупреждения: данные учебные, настоящая система не меняется, выйти можно кнопкой «Выйти из учебных данных».
  Внутри учебного режима переход к другой главе идёт без вопроса.
- Полоса «Учебные данные» видна весь показ, как и раньше.
- Адрес показа строит код по белому списку (`Tour.url`): путь страницы и только `tour`, `ch` или `all`, `demo`,
  `play`, `lang`. Рабочие `api`, `assist`, `fixture`, `latency`, `drop`, `uid` и прочее не переходят. Рабочие планы,
  история и секреты в урок не переносятся: хранилище показа — копия в памяти (п. 5).
- Рабочий адрес запоминается в `sessionStorage` вкладки (`tourBack`, только для той же страницы). Выход из показа
  и из отказа показа возвращает на него с `#learn=<глава>`: в той же вкладке, с прежними параметрами. Вход не теряется,
  потому что вкладка та же и сеанс консоли тот же.

**Файлы.** `assets/tour.js`, `index.html` (`learnPlay`), `tests/ui-learn.js`, `tests/ui-assist.js`.

**Как проверить.** `tests/ui-learn.js`: предупреждение и «Отменить»; белый список адреса; весь путь в одной вкладке:
рабочий адрес с `assist`, `fixture` и своим параметром → показ без них, с полосой, без службы → выход на тот же адрес
и ту же главу. `tests/ui-assist.js`: кнопка карточки — сначала предупреждение.

## 5. Изоляция и два отказа без перехода к рабочей системе

**Что изменено.**

- **Сервер показа не загрузился** (в том числе из-за CSP) или в сборке нет обучения: отказ показа поверх страницы,
  «Показ не запущен» и причина. Проверка стоит в самом начале кода `index.html`: код страницы дальше не выполняется
  и к API не обращается. `tour/demo` консоль не снимает, `location.replace` на рабочий адрес нет. Выйти можно кнопкой
  «Вернуться к работе» на рабочий адрес (п. 4). Прежняя ветка «снять учебные параметры и `location.replace`» убрана.
- **Хранилище не подменилось** (`Object.defineProperty(window, "localStorage", …)` упал или не подействовал): тот же
  отказ. Страница на настоящем хранилище не работает.
- **Внешняя служба ассистента в учебном режиме запрещена** из всех источников: `?assist=`, метка `consolem-assist`,
  `consolem-assist-public` (и публичная по умолчанию на `altumur.github.io`). `asstServiceUrl` проверяет `Tour.demo`.
  Чистая часть вынесена в `asstServiceUrlOf(search, host, meta, demo)` для проверки. Обычная автономная демо-страница
  вне учебного режима работает как раньше.
- В учебном режиме панель ассистента пишет: «Учебный пример: отвечает заглушка, а не живая модель».
- `?demoFail=server|storage` — проверка отказов. Параметр только отказывает: другого хода он не включает.
  В сборке `demoFail=server` не загружает файлы `demo/`.

**Файлы.** `assets/tour.js`, `index.html`, `assets/i18n-en.js`, `tests/ui-learn.js`, `tests/ui-assist.js`.

**Как проверить.** `tests/ui-learn.js`. Оба отказа проверены отдельно: с рабочим адресом в query `api` и без него.
Без query адрес API — метка `consolem-api`: она есть в сборке под CSP (`check_webui.py`), в макете `check_ui.py` её нет.
Ожидаем понятный отказ, учебные параметры на месте, ноль запросов к рабочему API, настоящий `localStorage` не изменился.
Разговор в учебном режиме с `?assist=` и добавленной меткой `consolem-assist` идёт без обращений к службе.
`tests/ui-assist.js`: три источника службы, обычная страница и учебный режим.

## 6. Неполная поставка, недоступная модель, без интернета

- Неизвестный ID, удалённая глава, чужая версия каталога: показа нет, предложен каталог своей поставки (п. 2, п. 3).
- Каталога или учебных файлов нет, в том числе `--without-learn`: раздела и кнопки запуска нет. Ссылка ассистента
  даёт объяснение без кнопки. `learn-catalog.json` — `available: false`. Адрес с `?demo` — отказ показа «nolearn».
- Модель недоступна (ошибка хода, служба не отвечает): в панели строка «Готовые учебные главы работают без ассистента:
  раздел «Обучение» и поиск в шапке» и кнопка «Открыть «Обучение»». Поиск в шапке находит главы, как раньше.
- Без интернета и внешней службы: каталог, поиск и туры работают без внешних обращений. `ui-learn` проверяет показ
  каждой темы: обращений за пределы своей страницы нет.
- Ни одна ошибка обучения не включает рабочий API (п. 5).

**Файлы.** `index.html`, `tests/ui-assist.js`, `tests/ui-learn.js`.

## 7. Главы о работе с ассистентом и совместные проверки

**Что изменено.** Новая тема `assistant` «Как работать с ассистентом», шесть глав на встроенной заглушке. В теме
и первой главе прямо сказано: отвечает заглушка, а не живая модель. Учебное «Применить» меняет только учебные данные.

| ID | Глава | Что показывает |
|---|---|---|
| `assistant.stub` | Пример с заглушкой | строка в панели «отвечает заглушка, а не живая модель» |
| `assistant.question` | Просьба и вопрос | просьба → вопрос «На какой камере?» → ответ → план |
| `assistant.check` | Проверка плана | «Слова модели» отдельно, пересказ словами формы, «Только журнал», учебное «Применить» |
| `assistant.refused` | Отказ | `refused`: поля нет в описании, ничего не изменилось |
| `assistant.conflict` | Конфликт версии | другой администратор правит правило, пока план ждёт; отказ строки, «Спросить заново» |
| `assistant.ask` | Вопрос оператору и эскалация | правила с `ask` и `escalate`, создаются в «Только журнал»; учебные вопросы не уходят операторам |

План настройки камер через групповую карточку в главы не вошёл: в учебном режиме все камеры этого плана пропускались.
Поэтому проверка и «Применить» показаны на плане правила.

**Проверки.** Расширены `tests/ui-learn.js`, `tests/ui-assist.js`, `tests/api-assist.js`; перечень — в пунктах выше.
