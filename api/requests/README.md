# Запросы к API от команд VMS

Здесь лежат запросы команд, которые делают бэкенд конфигуратора за своей VMS, и наши ответы. Один запрос — один файл `…-request.md`, ответ на него — отдельный файл рядом с тем же началом и `-response.md` в конце: при сортировке по имени ответ сразу под запросом, запрос остаётся таким, каким его прислали, а ответ можно дополнять, не трогая запрос.

## Как прислать запрос

1. Файл `ГГГГ-ММ-ДД-команда-тема-request.md`, команда и тема — по-английски, без транслитерации, например `2026-10-29-w2c-capabilities-request.md`. В шапке: дата, команда, **коммит контракта**, по которому вы работаете, и `Статус: новый`.
2. Пункты пронумеруйте. Тогда в ответе можно сослаться: «п. 2 — сделано в `abc1234`».

Добавьте строку в таблицу ниже и закоммитьте в `main`.

## Ответ

Ответ — файл `ГГГГ-ММ-ДД-команда-тема-response.md`, с тем же началом, что у запроса, например `2026-10-29-w2c-capabilities-response.md`. В шапке — ссылка на запрос, разделы — по пунктам запроса, с теми же номерами. По каждому пункту: что решили, в каком коммите сделано и где смотреть (раздел `BACKEND.md`, тест). Когда ответ готов, в шапке запроса и в таблице меняется статус, а в шапке запроса появляется ссылка на ответ.

| Статус | Значит |
|---|---|
| новый | запрос пришёл, ещё не разобран |
| в работе | разобран, делается |
| отвечен | ответ по всем пунктам записан |
| отклонён | не делаем; почему — в ответе |
