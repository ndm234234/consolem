# Запросы к API от команд VMS

Здесь лежат запросы команд, которые делают бэкенд конфигуратора за своей VMS, и наши ответы. Один запрос — один файл, ответ — в том же файле, разделом «Ответ» под запросом: вопрос и ответ видны рядом, история правок одна.

## Как прислать запрос

1. Файл `ГГГГ-ММ-ДД-команда-тема.md`, тема — латиницей, например `2026-10-29-w2c-vozmozhnosti.md`. В шапке: дата, команда, **коммит контракта**, по которому вы работаете, и `Статус: новый`.
2. Пункты пронумеруйте. Тогда в ответе можно сослаться: «п. 2 — сделано в `abc1234`».

Добавьте строку в таблицу ниже и закоммитьте в `main`.

## Ответ

Под запросом — раздел «Ответ». По каждому пункту в нём: что решили, в каком коммите сделано и где смотреть (раздел `BACKEND.md`, тест). Статус в шапке файла и в таблице меняется вместе с ответом.

| Статус | Значит |
|---|---|
| новый | запрос пришёл, ещё не разобран |
| в работе | разобран, делается |
| отвечен | ответ по всем пунктам записан |
| отклонён | не делаем; почему — в ответе |
