## Что проверить

1. **Новые поля пресета `presets[]`** (все необязательные, только чтение):
   - `savedOnDevice` — `true`: камера записала положение; `false`: у пресета есть только имя. Нет поля — не известно;
   - `pan`, `tilt` — от -1 до 1, `zoom` — от 0 (широко) до 1 (узко): записанное положение в обобщённом пространстве ONVIF. Нет поля — камера не сообщила.

   `PUT presets/{n} {name}` положение не меняет; новая запись только с именем получает `savedOnDevice: false`. `PUT presets/{n} {}` пишет положение и `savedOnDevice: true`. Ваш бэкенд знает эти значения (ONVIF `GetPresets` → `PTZPosition`)? Подходит ли обобщённое пространство ONVIF?
2. **`PtzMove.iris`** — скорость диафрагмы от -1 до 1, больше 0 — открыть. Нет поля — диафрагма стоит. Ваш бэкенд может управлять диафрагмой (ONVIF Imaging `Move`)?
3. **Поведение встроенного сервера.** Он считает положение камеры по аренде движения: скорость 1 за 10 с даёт 1 по оси. Повтор `PUT {}` без движения — «менять нечего». Первый `PUT {}` у пресета без полей положения теперь меняет запись (версия объекта и шаг отката), раньше это было «менять нечего».
