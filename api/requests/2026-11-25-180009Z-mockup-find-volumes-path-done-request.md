## Что проверить

1. **Параметр `path`** (string, необязательный) у `findVolumes` вида `archive.local`. Сервер ищет тома только в этой папке и в её подпапках. Ваш бэкенд умеет искать тома в одной папке диска сервера?
2. **Адрес тома для сравнения.** Файл `.afs` — путь `dir\file`, папка объектного хранилища — `dir`, раздел SolidStore целиком — корень диска (`D:\`). Папка `D:\Axxon` не захватывает `D:\AxxonArchive`: граница — косая черта.
3. **Запись пути.** Регистр, косая черта в конце и вид косой черты (`D:/Axxon`) не важны. `D:` без косой черты — корень диска.
4. **Без параметра или с пустым** — тома всех дисков сервера, как в 1.3. Папки нет — пустой список, а не отказ: нового отказа на прежнем запросе нет.

## Сверх запросов

- Консоль шлёт `path`, только если вид объявил его в `params` команды. Система на 1.3 получает прежний запрос без папки.
- «Обзор…» у поля папки — заглушка: консоль подставляет корень первого не системного диска. Выбора папки на сервере в контракте нет. Если он вам нужен, напишите — сделаем запросом.
- Новый том (и том с записями) теперь идёт в план карточки хранилища и уходит шагом `createUnit` операции, а не отдельным `POST /units`. У плана с томом, у которого `attachExisting`, нет «Отменить»: откат шага create удалил бы том, а настоящий сервер — и его файлы с записями.
