# `vms.archive/1` — Хранилище

Версия 1.1 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.camera/1` с 1.0, `vms.edge/1` с 1.0, `vms.server/1` с 1.0, `vms.volume/1` с 1.0

Виды эталонного набора: `archive.local`, `archive.network`, `archive.cloud`, `archive.backup`, `archive.edge`, `archive.incidents`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `admits` | boolean | «Принимает записи»: Принимает ли архив записи камер. false — новые привязки не принимаются, камера выбрать его не может | 1.0 |
| `encrypted` | boolean | «Шифрование» | 1.0 |
| `provider` | string \| null | «Провайдер»: Облачный провайдер (не меняется после создания) | 1.0 |
| `recordMode` | string: `backup`, `always` | «Когда писать»: Как пишет архив на весь сервер: постоянно или только при сбое. Значения — archiveModes вида. Нет поля — режим «Авто»: при сбое, а у камеры без основной записи в кластере из одного — постоянно | 1.0 |
| `retentionDays` | integer | «Срок записи, дней»: Глубина хранения; 0 — без ограничения. Значение 0 сервер может отвергнуть: `422 NOT_SUPPORTED`, если сервер хранит запись не меньше дня | 1.0 |
| `storage` | string: `block`, `object` | «Тип хранения» | 1.0 |
