# `vms.server/1` — Сервер

Версия 1.3 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.archive/1` с 1.0, `vms.edge/1` с 1.0, `vms.webserver/1` с 1.0

Виды эталонного набора: `server`.

|---|---|---|---|
| `allocated` | boolean (только чтение) | «Распределён»: False — сервер найден в сети домена, но ещё не добавлен («Нераспределённые») (только чтение) | 1.0 |
| `dns` | string | DNS Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |

| `ip` | string | «IP» Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `labels` | массив string | Метки сервера: по ним размещаются камеры, детекторы, записи, правила | 1.0 |
| `netmask` | string | Маска сети Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |

## Состояние (`status.observed`)

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `class` | string: `server`, `camera` | чем представился стучащийся в домен: сервер или камера; человек подтверждает это при приёме | 1.0 |
| `disks` | массив object | диски сервера: на них ставятся тома локальных хранилищ. `freeBytes` (с 1.3) — свободное место диска сейчас: тома всех хранилищ на диске уже вычтены, раздел хранилища целиком оставляет 0. Нет поля — система не сообщает место: консоль не проверяет размер тома по диску | 1.0 |
| `fingerprint` | string | отпечаток стучащегося сервера: администратор сверяет его перед приёмом (`move` с `params.fingerprint`) | 1.0 |
| `gpu` | object \| null | видеокарта сервера: для серверных детекторов, метка `gpu` Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `ownConfig` | object | что создали на этом сервере: макросы (macros), раскладки (layouts), карты (maps), группы объектов (groups), роли (roles), пользователи (users). Исключение из домена и перенос в другой домен удаляют это: окно подтверждения называет числа. После исключения все числа 0, откат их не возвращает Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.2 |
| `telemetry` | object | нагрузка сервера: процессор, память, сеть, диск Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
