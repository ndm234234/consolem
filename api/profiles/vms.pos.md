# `vms.pos/1` — Источник событий (касса)

Версия 1.2 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.camera/1` с 1.0, `vms.live/1` с 1.0

Виды эталонного набора: `eventsrc`. Предметные пути: `/units/{uid}/pos/raw`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `overlays` | массив object, до 16 | Камеры титров и зона на каждой: `{cameraId, area: {x, y, w, h}}`, доли кадра 0–1, `x + w ≤ 1`, `y + h ≤ 1`; не больше 16, камера один раз. Заменяет `cameraId` Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `cameraId` | string \| null — uid (`vms.camera/1`) | **Устарело.** Первая камера `overlays`. Правка одного `cameraId` заменяет первую камеру списка (зона остаётся), `null` очищает список; правка с обоими полями — действует `overlays` | 1.0 |
| `overlayDelayMs` | integer | Титры источника событий: задержка показа, мс | 1.0 |
| `overlayDurationSec` | integer | Титры источника событий: сколько держать чек на экране после последней строки, с. 0 (и поле без значения) — держать до следующей строки; если касса молчала больше 10 секунд, новая строка начинает экран заново (как Display duration = 0 в Axxon One) | 1.0 |
| `overlayFont` | string | Вид титров: имя шрифта Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `overlayFontSize` | integer | Вид титров: размер шрифта, пункты Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `overlayColor` | string | Вид титров: цвет текста, #rrggbb Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `overlayBg` | string | Вид титров: цвет фона, #rrggbb Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `overlayBgTransparency` | integer | Вид титров: прозрачность фона, % (0 — сплошной фон, 100 — без фона) Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `receiptStartWords` | массив string, до 32 | Слова начала чека: строка со словом начинает чек. Сравнение посимвольно, регистр — по ignoreCase. Без слов начала и конца сервер не делит строки на чеки и поиск по чекам в архиве не работает Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `receiptEndWords` | массив string, до 32 | Слова конца чека: строка со словом заканчивает чек. При receiptSplit = none сервер их не проверяет Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `receiptSplit` | string: `skip`, `none` | Как делить строки на чеки (Repeats processing в Axxon One): skip — по словам начала и конца; none — только по словам начала, слова конца сервер не проверяет Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `ignoreCase` | boolean | Не учитывать регистр слов начала и конца чека Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `billsOnly` | boolean | Показывать в титрах только строки между словами начала и конца чека Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `eraseOnEnd` | boolean | Убирать строки с экрана после конца чека Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `words` | массив object | Подсветка: `msg`, `color`, `bg` и флажки `caseSensitive`, `wholeLine` (вся строка), `bgEnabled` | 1.0 |
| `protocol` | string: `tcp`, `udp`, `rs232` | Приём данных: протокол. rs232 требует comPort и baudRate; comPort, baudRate, parity и udpMaxPacket в одной правке с другим протоколом — 422 VALIDATION_FAILED. Когда правка меняет протокол и не называет эти поля, сервер сам снимает поля прежнего протокола (RS-232 или UDP). ip и port нужны tcp и udp Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `comPort` | string | RS-232: COM-порт (COM1, /dev/ttyS0). Только при protocol = rs232 Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `baudRate` | integer: `300`, `600`, `1200`, `2400`, `4800`, `9600`, `14400`, `19200`, `38400`, `56000`, `57600`, `115200`, `128000` | RS-232: скорость, бит/с. Только при protocol = rs232 Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `parity` | string: `none`, `even`, `odd` | RS-232: чётность. Только при protocol = rs232 Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `udpMaxPacket` | integer | UDP: наибольший пакет, байт. Только при protocol = udp Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `encoding` | string: `auto`, `utf8`, `dos2win` | Кодировка данных кассы: auto — Windows-1251, utf8, dos2win — DOS (CP866) Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `terminalType` | string | Тип терминала из списка драйвера (POSLegacy): XML PROTOCOL, SUPERMAG UKM, ALOHA… Список зависит от vendor; на стенде значение хранится без проверки по списку драйвера Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `parserFile` | string | Файл шаблона разбора данных на сервере: .txt — парсер XML, .prl — парсер POS. На стенде — заглушка: имя хранится, файл не читается и данные им не разбираются Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `processing` | string: `line`, `event`, `json` | Разбор данных: построчно, по событию или JSON. На стенде — заглушка: значение хранится, данные не разбираются Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `timeoutMs` | integer | Разбор данных: таймаут, мс Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `timeOffsetMs` | integer | Разбор данных: сдвиг времени титров, мс (отрицательный — раньше) Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `retalix` | boolean | Касса Retalix (драйвер POSLegacy) Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `enabled` | boolean | «Включено» | 1.1 |
| `ip` | string | «IP»: Адрес. У eventsrc — адрес сервера или имя кассы, у драйвера, что подключается сам, — адрес кассы; 0.0.0.0 и :: — 422 VALIDATION_FAILED, field: ip | 1.1 |
| `model` | string | «Модель»: Модель кассы или кассового ПО, для показа в карточке. Консоль только показывает значение | 1.1 |
| `port` | integer | «Порт» | 1.1 |
| `short` | string | «Короткое имя»: Номер для показа в дереве («3.3.1») | 1.1 |
| `vendor` | string | «Производитель» | 1.1 |
| `serverId` | string — uid (server) | Сервер: к которому подключены камера и регистратор (выводится из хранилища записи), сервер расчёта детектора, сервер службы. У eventsrc — запись: без него сервер выбирает система и предупреждает в faultText, переноса при падении нет | 1.1 |
