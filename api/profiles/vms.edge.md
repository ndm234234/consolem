# `vms.edge/1` — Встроенное хранилище устройства

Версия 1.2 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.archive/1` с 1.0, `vms.camera/1` с 1.0

Виды эталонного набора: `storage`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `replication` | object | Настройка репликации в архив сервера. `mode`: `off` — сервер сам не забирает (правила с `replicate` и ручной забор работают), `all` — забирает все записи и не держит живой поток. `archiveId` — хранилище сервера (вид с `replica` в `recordModes`); для `all` нужно, нет значения — хранилище записи камеры, нет и его — `422 VALIDATION_FAILED`, `/properties/replication`. `speedLimitMbps` — 0…1000, 0 без предела. `excludedCameras` — только у регистратора, камеры этого регистратора. Правка частичная Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.0 |
| `enabled` | boolean (только чтение) | «Включено» | 1.1 |
| `recordMode` | string: `none`, `always`, `motion`, `sched`, `replica`, `backup` | «Когда писать»: Режим записи. replica — забирать записи без постоянного потока. backup — живой поток только на время сбоя основной записи: только в extraArchives, на архиве, где это значение есть в recordModes его вида | 1.1 |
| `short` | string (только чтение) | «Короткое имя»: Номер для показа в дереве («3.3.1») Нет значения — у сервера нет такой возможности: особый экран поле не показывает (`absent`). | 1.1 |
