# `vms.camera/1` — Камера

Версия 1.7 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.archive/1` с 1.0, `vms.detector/1` с 1.0, `vms.edge/1` с 1.0, `vms.live/1` с 1.0, `vms.ptz/1` с 1.0, `vms.stream/1` с 1.0, `vms.talk/1` с 1.0, `vms.timeline/1` с 1.0

Виды эталонного набора: `camera`. Предметные пути: `/units/{uid}/recording-target`, `/units/{uid}/recording-days`.
