# `vms.stream/1` — Поток

Версия 1.3 · ведёт: mockup · смотрят правку: w2c

Использует: `vms.camera/1` с 1.0

Виды эталонного набора: `stream`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `bitrateKbps` | integer | «Битрейт»: cbr — битрейт потока, vbr — наибольший битрейт, кбит/с | 1.2 |
| `bitrateMode` | string: `vbr`, `cbr` | «Режим битрейта»: vbr — переменный битрейт, cbr — постоянный | 1.2 |
| `codec` | string | «Кодек»: Кодек потока. Набор зависит от устройства; examples — подсказки. Сервер записывает его в устройство, когда камера передаёт свои настройки устройству (x-dev); иначе значение сообщает устройство | 1.0 |
| `codecProfile` | string: `baseline`, `main`, `high` | «Профиль кодека»: Профиль H.264 или H.265. У MJPEG профиля нет: поле не учитывается | 1.2 |
| `deviceProfile` | string | «Профиль потока камеры»: Какой профиль устройства (например, профиль ONVIF) отдаёт этот поток. Значение — из deviceProfileOptions. Поля нет — профиль выбирает драйвер | 1.2 |
| `deviceProfileOptions` | массив string (только чтение) | Профили потоков, которые сообщает устройство. Нет поля — выбора профиля нет (только чтение) | 1.2 |
| `enabled` | boolean | «Включён»: false — сервер не берёт этот поток с камеры: нет видео, записи и детекторов на нём. Поля нет — включён | 1.2 |
| `fps` | integer | «к/с» | 1.0 |
| `gopFrames` | integer | «Опорный кадр каждые»: Расстояние между опорными кадрами (GOP), в кадрах | 1.2 |
| `height` | integer (только чтение) | «Высота» (только чтение) | 1.0 |
| `liveUse` | boolean | «В просмотре»: Поток можно выбрать над видео. Поля нет — можно. Поле консоли: в устройство не уходит | 1.2 |
| `quality` | integer | «Качество»: Качество изображения при vbr: 1 — низкое, 6 — наивысшее. Это и «Сжатие» (Compression Rate) Axxon One. При cbr не учитывается | 1.2 |
| `res` | string | Разрешение: ширина x высота, латинская x. Настройка, сервер передаёт её драйверу | 1.0 |
| `resOptions` | массив string (только чтение) | Допустимые разрешения этого потока или общий список разрешений устройства. Поток может принять не все: такое значение `res` отвергает само устройство. Нет поля — ввод руками (только чтение) | 1.0 |
| `rtspUrl` | string | «Адрес RTSP»: Адрес RTSP этого потока, если камера отдаёт его по своему адресу. Поля нет — поток идёт по rtspUrl камеры. Сервер хранит и отдаёт значение, сам поток не создаёт. В Axxon One это второй и третий адрес через «;» в поле адреса камеры | 1.3 |
| `smartCodec` | boolean | «Умный кодек»: H.264+, H.265+ и подобные режимы устройства. Поля нет — выключен | 1.2 |
| `streamId` | string (только чтение) | «Код потока»: Его принимают stream камеры и строки extraArchives (только чтение) | 1.0 |
| `width` | integer (только чтение) | «Ширина» (только чтение) | 1.0 |
