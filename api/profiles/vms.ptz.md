# `vms.ptz/1` — PTZ

Версия 1.1 · ведёт: mockup · смотрят правку: w2c

Использует: —

Виды эталонного набора: `camera`. Предметные пути: `/units/{uid}/ptz`, `/units/{uid}/presets/{n}`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `ptz` | boolean (только чтение) | Камера поворачивается. PTZ — свойство камеры, своей записи нет (только чтение) | 1.0 |
| `presets` | массив object (только чтение) | Сохранённые номера. Имя пустое — пресет сохранён без подписи, форма показывает его номером. Имя оператора старше имени драйвера (только чтение) | 1.0 |
| `presetMax` | integer (только чтение) | Предел номера пресета (только чтение) | 1.0 |
| `ptzEnabled` | boolean | «Включить»: false — оператор не поворачивает камеру: аренда движения (PUT ptz) и запись положения пресета — 422 NOT_SUPPORTED, туры и патрулирование не идут. Поля нет — включён | 1.1 |
| `ptzSource` | string: `self`, `port` | «Телеметрия»: self — поворотом управляет сама камера (её драйвер, ONVIF); port — поворотное устройство на порту другого устройства (ptzPort); подключив его, сервер ставит камере ptz: true. Поля нет — self | 1.1 |
| `ptzPort` | object \| null | «Порт»: порт телеметрии при ptzSource port — порт RS-485 канала IP-сервера или COM-порт сервера (unitId — объект с портом, port — имя порта). Скорость и чётность задают у порта: они общие для всех устройств на линии. Нет поля — порт не выбран | 1.1 |
| `ptzProtocol` | string | «Протокол»: протокол поворотного устройства при ptzSource port. Набор зависит от сервера; examples — подсказки | 1.1 |
| `ptzAddress` | integer | «Адрес»: адрес поворотного устройства на линии при ptzSource port; совпадает с переключателями на устройстве. Поля нет — 1 | 1.1 |
