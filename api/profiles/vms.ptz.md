# `vms.ptz/1` — PTZ

Версия 1.3 · ведёт: mockup · смотрят правку: w2c

Использует: —

Виды эталонного набора: `camera`. Предметные пути: `/units/{uid}/ptz`, `/units/{uid}/presets/{n}`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `ptz` | boolean (только чтение) | Камера поворачивается. PTZ — свойство камеры, своей записи нет (только чтение) | 1.0 |
| `presets` | массив object (только чтение) | Сохранённые номера. Имя пустое — пресет сохранён без подписи, форма показывает его номером. Имя оператора старше имени драйвера (только чтение). Профиль 1.2: savedOnDevice — положение записано в камере, pan, tilt, zoom — записанное положение; полей нет — не известно | 1.0 |
| `presetMax` | integer (только чтение) | Предел номера пресета (только чтение) | 1.0 |
| `ptzEnabled` | boolean | «Включить»: false — оператор не поворачивает камеру: аренда движения (PUT ptz) и запись положения пресета — 422 NOT_SUPPORTED, туры и патрулирование не идут. Поля нет — включён | 1.1 |
| `ptzSource` | string: `self`, `port` | «Телеметрия»: self — поворотом управляет сама камера (её драйвер, ONVIF); port — поворотное устройство на порту другого устройства (ptzPort); подключив его, сервер ставит камере ptz: true. Поля нет — self | 1.1 |
| `ptzPort` | object \| null | «Порт»: порт телеметрии при ptzSource port — порт RS-485 канала IP-сервера или COM-порт сервера (unitId — объект с портом, port — имя порта). Скорость и чётность задают у порта: они общие для всех устройств на линии. Нет поля — порт не выбран | 1.1 |
| `ptzProtocol` | string | «Протокол»: протокол поворотного устройства при ptzSource port. Набор зависит от сервера; examples — подсказки | 1.1 |
| `ptzAddress` | integer | «Адрес»: адрес поворотного устройства на линии при ptzSource port; совпадает с переключателями на устройстве. Поля нет — 1 | 1.1 |
| `tours` | массив object | Туры PTZ камеры: тур водит камеру по пресетам. id — имя тура для команды правила ptz.tour; steps — точки: preset — номер пресета, dwellSec — сколько стоять, speed — скорость переезда (1–100, нет поля — скорость камеры); order — seq по списку или random; pauseSec — пауза между кругами; onManual — что делает тур, когда оператор взял управление: pause — пауза, через resumeSec без управления тур продолжает с той же точки (resumeFrom same) или с первой (first), stop — тур останавливается; idleStartSec — тур запускается сам, когда камерой не управляют столько секунд (так только один тур камеры). Пресет точки сервер не проверяет: пресет могли удалить позже, консоль показывает такую точку ошибкой. Пуск, пауза и состояние тура — API видео. Нет поля — туров нет | 1.3 |
| `tourMax` | integer (только чтение) | Предел числа туров камеры (ONVIF MaximumNumberOfPresetTours, Axis MaxGuardTour). Нет поля — предел не задан (только чтение) | 1.3 |
| `tourStepsMax` | integer (только чтение) | Предел числа точек в туре. Нет поля — предел не задан (только чтение) | 1.3 |
