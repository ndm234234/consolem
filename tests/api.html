Тесты API конфигуратора

Сценарии «запрос → ответ и новое состояние → ошибки» по разделам: те же запросы, что у интерфейса. Каждый ответ сверяется со схемой api/openapi.json, в конце — покрытие операций контракта. Двойной клик — проверяется встроенный сервер прототипа. Тестовый стенд бэкенда — api.html?api=https://адрес: нужны служебные операции /test/reset, /test/clock, /test/events и CORS (api/BACKEND.md). Петля — api.html?api=loopback: тот же встроенный сервер по HTTP, за Service Worker; запуск — python3 tools/check_loopback.py. Один тест — ?only=<имя>.
