Бесперебойность записи: Edge + Backup + Защита каждой секунды

Кадр не теряется ни при обрыве канала, ни при падении сервера записи, ни при потере кворума кластера, ни при сбросе часов камеры

Ни одной «слепой секунды» на переключении
Предзапись из RAM-кольца закрывает окно детектирования отказа,
а умная дозапись сшивает архив из Edge и Backup без дублей

Backup • Zero Blind-Spot 01 / BACKUP & PRE-ROLL

Резервная запись с предзаписью ДО момента сбоя

  • Два режима резерва: параллельно на втором сервере (always, анти-аффинность spread_by: cam) или экономно только при аварии основного (when: offline).
  • Никакой дыры на время обнаружения отказа: резерв держит хвост в RAM-кольце и при аварии основного регистратора сбрасывает на диск секунды с ключевого кадра ДО падения.
  • Живучий воркер камеры: размещается рядом с резервом (prefer: backup), чтобы смерть основного сервера не оборвала приём потока.
Отличает аварию от штатного enabled: false ✓ 0 секунд потери на failover
Edge • Smart Eviction 02 / EDGE SD & OWED SPANS

Умная SD-карта: бережёт то, что сервер ещё не получил

  • Приоритет недоставленного (CardBuffer.owed): при нехватке места карта удаляет старейшие уже подтверждённые сервером сегменты (delivered.json), сохраняя недокачанные дыры до последнего.
  • Изоляция от медленного флеша: изношенная SD-карта никогда не блокирует живой поток и CamRing — переполнение очереди режет только запись карты до следующего keyframe.
Фоновая проверка health: ok | degraded | failed ✓ Спасение дыр при долгом обрыве
Backfill • Gap Healing 03 / DELTA BACKFILL

Точечная дозапись дыр из Edge и Backup

  • Математика покрытий (desired − actual = gaps): основная запись сверяет свой индекс с картой покрытия (coverage) в пульсе камеры или резервного сервера.
  • Докачка только недостающего: никаких полных копирований — запрашиваются только пропущенные интервалы с границы ключевого кадра.
  • Чистое разделение потоков: дозапись идёт в <rec>/e<n>/backfill, не мешая живому потоку live, а при чтении прозрачно склеивается.
Коалесцирование соседних дыр (COALESCE_GAP) ✓ Бережёт узкий WAN-аплинк
Control-Plane Survival 04 / UNCONFIRMED LEASE

Запись не останавливается при падении кворума

  • Разделение may_write и may_act: если управляющее хранилище (Raft / configstore) недоступно, аренда переходит в неподтверждённую — внешние действия заблокированы, но запись видео в том продолжается.
  • Бесконфликтные эпохи (e<n>, e<n+1>): даже если другой узел перехватил камеру в новой эпохе, оба тома хранят свои потоки без порчи данных и сшиваются на таймлайне.
Автономная работа до unconfirmed_max ✓ Падение контроллера ≠ потеря архива
Clock Immunity 05 / CAMLINE TIME ANCHOR

Иммунитет к сбросу часов (1970 год) и скачкам NTP

  • Монотонная линия времени (CamLine + line.json): камера без батарейки RTC после потери питания сразу пишет видео по внутреннему монотонному счётчику (boot_id).
  • Мгновенное переякоривание без перезаписи видео: когда появляется интернет и NTP, сегменты на карте получают реальное время атомарным переименованием <start>@<offset>.smpl.
Защита от прыжков часов вперёд/назад ✓ Архив никогда не «улетает в 1970-й»
Storage & Drain Safety 06 / DRAIN, RING & KEEPS

Безопасный Drain, предформатированное кольцо и Keeps

  • Drain ждёт сброса всех буферов: при выводе сервера на обслуживание статус safe наступает только при units == 0 и pending_writes == 0 — хвосты дозаписи не обрываются.
  • Кольцевой ObjectStorage + тома incidents: предформатированный по квоте том не переполняет диск и меняет размер на лету, а важные события копируются в неприкосновенный том incidents (keeps с крипто-дайджестом).
Детерминированное вытеснение без фонового GC ✓ 0 потерь при обновлениях и ротации
