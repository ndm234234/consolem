Backup • Zero Blind-Spot 01 / BACKUP & PRE-ROLL

Backup Recording with Pre-Roll BEFORE Crash Detection

  • Two backup modes: continuous dual write on a second server (always, anti-affinity spread_by: cam) or standby on primary failure (when: offline).
  • Zero detection-window gap: standby backup keeps a rolling tail in RAM and, when the primary goes silent, flushes video starting from the keyframe BEFORE the crash.
  • Survivable camera worker: placed next to the backup (prefer: backup) so primary server death never drops ingestion.
Distinguishes crash from intentional enabled: false ✓ 0 sec lost on failover
Edge • Smart Eviction 02 / EDGE SD & OWED SPANS

Smart SD Card: Preserves What the Server Hasn’t Received

  • Undelivered-first retention (CardBuffer.owed): when full, the SD card evicts the oldest already-delivered segments first (delivered.json), protecting unuploaded gaps to the very last byte.
  • Isolated from slow flash: a worn or lagging SD card never stalls live streaming or CamRing — queue overflow cleanly trims only card writes to the next keyframe.
Background health monitoring ok | degraded | failed ✓ Protects gaps on slow WAN links
Backfill • Gap Healing 03 / DELTA BACKFILL

Surgical Gap Backfill from Edge & Backup

  • Coverage set math (desired − actual = gaps): the primary archive compares its volume index against the coverage summary in camera or backup heartbeats.
  • Transfer only what’s missing: no bulk file copying — only missing time spans are pulled, aligned to keyframe boundaries.
  • Clean stream separation: backfill writes into <rec>/e<n>/backfill without disrupting live, seamlessly merging on playback.
Coalesces adjacent gaps (COALESCE_GAP) ✓ Saves constrained WAN bandwidth
Control-Plane Survival 04 / UNCONFIRMED LEASE

Recording Continues Even When Cluster Quorum Drops

  • Decoupled may_write vs. may_act: if the cluster config store (Raft / configstore) becomes unreachable, the lease enters unconfirmed state — external actions pause, but local volume recording continues uninterrupted.
  • Conflict-free epochs (e<n>, e<n+1>): even if another node claims the camera under a new epoch, both volumes store their streams cleanly and stitch on the timeline.
Autonomous recording up to unconfirmed_max ✓ Control plane outage ≠ archive loss
Clock Immunity 05 / CAMLINE TIME ANCHOR

Immunity to Clock Resets (Year 1970) & NTP Jumps

  • Monotonic camera timeline (CamLine + line.json): an RTC-less camera booting without internet immediately records against a monotonic boot counter (boot_id).
  • Zero-copy time anchoring: once NTP locks, existing SD segments acquire wall-clock time via an atomic rename <start>@<offset>.smpl without rewriting video bytes.
Immune to forward/backward NTP clock jumps ✓ Archive never vanishes into 1970
Storage & Drain Safety 06 / DRAIN, RING & KEEPS

Zero-Loss Node Drain, Pre-Allocated Ring & Incident Keeps

  • Drain waits for buffer flush: during planned maintenance (POST /drain), safe status requires both units == 0 and pending_writes == 0 — no in-flight tails are cut off.
  • Ring ObjectStorage + incidents volumes: pre-formatted quota rings never suffer sudden disk-full failures and resize live, while critical clips are copied to an immutable incidents volume (keeps with cryptographic digests).
Deterministic FIFO eviction with zero background GC spikes ✓ Zero loss during upgrades & rotation
