# Промты

Промты для ИИ — задачи и вопросы, которые отдаются агенту целиком. В начале каждого файла — дата, коммит, на котором промт написан, для какого ИИ и зачем. Промт называет файлы и цифры репозитория, они устаревают: перед запуском сверить с нынешним состоянием. Разделы `CLAUDE.md` «Контракт API», «Запросы команд VMS» и «Перенос в основной» с 2026-11-12 лежат в скиллах проекта `api-contract`, `vms-requests` и `proto-promote` (`.claude/skills/`).
